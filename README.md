# Vlad Nadymov

Founder of [selltostate.com](https://www.selltostate.com/): search for government contracts and public tenders.
5M+ procurement notices from 73 countries. Co-founder of [Beton](https://github.com/getbeton). Based in Limassol, Cyprus.

## What I build

[Beton](https://github.com/getbeton) builds concrete data foundations for AI agents. We collect public data
from many sources, clean it and give it to agents through MCP servers and APIs.

[selltostate.com](https://www.selltostate.com/) is the first data product: government tenders, contract awards,
public buyers and suppliers. Use it in the browser, through the API, or from an agent through MCP.

## Open source

### Government contract data for agents and developers

- [selltostate-mcp](https://github.com/getbeton/selltostate-mcp): MCP server for tenders, buyers and suppliers.
- [selltostate-skills](https://github.com/getbeton/selltostate-skills): agent skills for Claude, ChatGPT/Codex, Cursor and Gemini CLI.
- [selltostate-cli](https://github.com/getbeton/selltostate-cli): command-line client.
- API clients: [Python](https://github.com/getbeton/selltostate-py) · [TypeScript](https://github.com/getbeton/selltostate-ts) · [Java](https://github.com/getbeton/selltostate-java) · [Kotlin](https://github.com/getbeton/selltostate-kotlin) · [Rust](https://github.com/getbeton/selltostate-rust) · [Ruby](https://github.com/getbeton/selltostate-ror)
- [n8n-nodes-selltostate](https://github.com/getbeton/n8n-nodes-selltostate) and [zapier-selltostate](https://github.com/getbeton/zapier-selltostate): triggers on new tenders for no-code workflows.
- [how-governments-buy-ai](https://github.com/getbeton/how-governments-buy-ai): rerun our study "How governments buy AI" on live procurement data.

### Data and agent tools

- [dryfit](https://github.com/getbeton/dryfit): synthetic analytics databases with hidden ground truth, to test agents on signal discovery.
- [vobo](https://github.com/getbeton/vobo): human review for AI output.
- [oss-pricing-data](https://github.com/getbeton/oss-pricing-data): open dataset of pricing for 20 open-source tools, 2023 vs 2026. CC BY 4.0.
- [inspector](https://github.com/getbeton/inspector) and [beton-ai](https://github.com/getbeton/beton-ai): open-source revenue intelligence. Finds buying signals in PostHog and CRM data.
- [seqd](https://github.com/getbeton/seqd): self-hosted email sequencer.
